# Image credits

All illustrations in this directory are **original, hand-built flat-style
SVGs** created for this project, drawn in a visual language inspired by
[unDraw](https://undraw.co) (open illustration style: simple flat shapes,
limited palette, no gradients-for-gradient's-sake) but not copied or traced
from any unDraw asset.

Why original instead of downloaded unDraw files: unDraw's site serves its
picker and color customization through a JavaScript app rather than a stable,
directly-curlable SVG endpoint, so programmatic download during this build
was not reliable enough to guarantee a correctly-licensed, unmodified file.
Per the project brief, original flat-style illustrations in the same visual
language were built by hand instead - they are original work, not copied
from unDraw or any other source.

If genuine unDraw SVGs are preferred later, they are free to use under the
unDraw license (MIT-like, no attribution required) at https://undraw.co -
swap any file below with a downloaded + recolored unDraw SVG and update this
note.
